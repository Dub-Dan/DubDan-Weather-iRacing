# DubDan-Weather-iRacing Installation Instructions

## Step 1: Install the Wind Arrow Asset
1. Download or copy `WindArrow.png` from this repository.
2. Paste it into the SimHub icons library folder:  

   C:\Program Files (x86)\SimHub\ImageLibrary\Icons\

- If the `Icons` subfolder does not exist, create it.
- You may need administrator privileges to copy files here.

## Step 2: Import the Overlay
1. Locate and double-click the file `DubDan-Weather-iRacing.simhubdash`.
2. SimHub will automatically open (or come to the foreground) and prompt you to import the overlay.
3. Confirm the import to add it to your overlays collection.

## Step 3: Set Up Automatic Loading (Recommended for iRacing)
To make the overlay appear automatically when launching iRacing:

1. Launch any iRacing session (practice, test, qual, race, etc.).
2. Open SimHub and navigate to **Dash Studio → Overlays**.
3. Click **New overlay layout** at the top.
4. Add the overlay:
- Search for **DubDan-Weather-iRacing** and add it.
5. Position the overlay(s):
- Place **DubDan-Weather-iRacing** in your preferred location (e.g., corner or side).
- If using mirror flags, align them over iRacing's virtual mirror area.
6. Click **Save** and give the layout a descriptive name (e.g., "iRacing Weather Auto").
7. In the **Overlays** list, find your new layout.
8. Click the dropdown menu next to it and select **Current Game** (or iRacing specifically if listed).
9. Close and restart iRacing to test—the overlay should now load automatically on session start.

## Troubleshooting Tips
- **Wind arrow not visible?** Verify `WindArrow.png` is correctly placed in the `ImageLibrary\Icons` folder, then restart SimHub.
- **Overlay missing or not loading?** Ensure SimHub is running before starting iRacing, and confirm the layout is assigned to "Current Game" or iRacing.
- **No weather data shown?** iRacing must provide weather telemetry (visible in-game during sessions with variable weather).

That's it—your overlay should now be fully installed and ready for use!

Happy sim racing! 🏁
