# DubDan-Weather-iRacing

iRacing-specific SimHub overlay focused on delivering clear, actionable weather and track condition intelligence.

Designed for drivers who want to stay ahead of changing conditions without cluttering the screen.

## Key Features

- **Smart Rain Threat Indication**  
  Color-coded pressure background (green → yellow → orange → red) that anticipates incoming rain using a blend of current humidity, pressure, temperature trends, and session context — switches to a dedicated "rain stopping" mode once precipitation begins.

- **Dynamic Track Usage Coloring**  
  Track rubber state (Clean → Maximum Usage) displayed with intelligent color coding that adapts based on whether the track is declared dry or wet — helps instantly judge grip levels at a glance.

- **Real-time & Historical Weather Readouts**  
  - Air temperature, track temperature, humidity, barometric pressure  
  - Current precipitation percentage  
  - Track wetness description (Dry → Very Lightly Wet → Lightly Wet → etc.)  
  - Wind speed and direction (with animated arrow indicator)  
  - **Session averages shown in brackets** for most values (rolling 1-hour reference) to quickly compare current conditions against recent trends

- **Usage Levels Highlighted**  
  Clear visual tiers ("Moderate Usage", "Moderately High Usage", etc.) with matching background colors to emphasize how aggressively the weather/track is affecting grip and setup decisions.

- **Clean, Minimal Design**  
  Dark theme, compact layout, transparent background — sits nicely in a corner or beside your mirror without blocking the view.

## Installation

See the dedicated installation instructions in the repository (or README_install.md if you split it).

Quick summary:
1. Place `WindArrow.png` in `C:\Program Files (x86)\SimHub\ImageLibrary\Icons\`
2. Double-click `DubDan-Weather-iRacing.simhubdash` to import
3. Set up an automatic overlay layout assigned to iRacing for seamless loading

## Compatibility
- Optimized for **iRacing** (relies on iRacing-specific telemetry properties)
- Requires SimHub (recent versions recommended)

## Notes
- Best results in variable weather sessions (practice/test/race with dynamic forecasts)
